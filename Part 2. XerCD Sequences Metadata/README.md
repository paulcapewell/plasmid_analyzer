# P2 Analyze Sequence and Metadata of Hits

These scripts are based on Paul Capewell's earlier 'plasmid_analyzer' which was a python port of Xerscript_v4.m

These scripts:
- extract relevant sequences around Xer-site hits, or full plasmid sequences by fetching GenBank records
- sequences collected include:
        - 3kb and 218bp including the full xer site
        - the xerd, crossover region, and xerc sites seperately
        - upstream and downstream sequences (250bp, 1kb, 3kb) 
- summarizes this data in a summary spreadsheet
        - Accession number
        - plasmid name
        - sequence length
        - GC content
        - xer site coordinate and orientation
        - xer site sequence (including specifically xerD, crossover region, xerc)
        - gene annotations adjacent to the xer site
        - host species/taxonomy

- does *not* run clinker (that was moved to a seperate folder of the plasmid_analyzer program)

## Workflow

Run the scripts in the following order:

1. `201_extract_sequences.py`
2. `202_summary_spreadsheetslpy`

Each script uses output files generated by the earlier steps.


## Requirements
- Python 3.9 or newer
- Biopython
- Internet access to fetch GenBank records from NCBI when running 01_process_xercd_screen_hits.py 
    (unless the required GenBank files already exist in output_folder/full_sequences_of_hits_GBKs)
- A gzipped FASTA database named `bacterial_plasmids_curated.fa.gz` in:
    `input_folder`/`full_plasmid_sequence_database`/
